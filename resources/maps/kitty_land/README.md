# Kitty Land Map Pack

`kitty_land_catalog.json` contains 10 cute kitten and cat themed maps ordered by increasing difficulty.

Each map includes:

- deterministic seed
- map size
- ground regions
- water regions
- roads and moving-car routes
- people paths
- building zones
- prop spawn zones
- stacked object spawn points
- a `preview_png` reference image under `res://assets/maps/kitty_land/`

The PNG previews are top-down reference diagrams generated from the same map data. They are not loaded by the current prototype yet.
